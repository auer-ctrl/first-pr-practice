# first-pr-practice

A tiny practice repository for learning the GitHub pull request workflow.

## What's here

`greet.py` contains a single function, `greet(name)`, that returns a
friendly greeting string.

```python
from greet import greet

print(greet("world"))  # Hello, world!
print(greet(""))       # Hello, stranger!
```

## Running

```bash
python greet.py
```
